# Documentación de FilmForum

FilmForum es una aplicación PHP y Twig para gestionar películas, usuarios y
comentarios mediante Docker Compose.

- [Inicio](inicio.md): instalación y uso básico.
- [Arquitectura](arquitectura.md): estructura y funcionamiento general.
- [Docker y entorno](docker.md): contenedores, volúmenes y variables.
- [Base de datos](base-datos.md): tablas, datos iniciales y copias.
- [Seguridad y administración](seguridad.md): roles, superusuario y protección.
